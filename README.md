# Foundations of Cybersecurity
### Google Cybersecurity Professional Certificate — Course 1

This repository documents what I learned in **Foundations of Cybersecurity**, the first course in the Google Cybersecurity Professional Certificate.

## What I Learned

### 1. Introduction to Cybersecurity
- How cybersecurity helps protect systems, networks, devices, and data.
- The importance of protecting sensitive information.
- The responsibilities of an entry-level cybersecurity analyst.

### 2. Core Security Concepts
- **Confidentiality:** Ensuring information is accessible only to authorized people.
- **Integrity:** Protecting information from unauthorized changes.
- **Availability:** Ensuring systems and information are accessible when needed.

These principles form the **CIA triad**.

### 3. Threats, Vulnerabilities, and Risks
- **Threat:** Something that could cause harm to a system or organization.
- **Vulnerability:** A weakness that could be exploited.
- **Risk:** The possibility of harm and its potential impact.

### 4. Security Domains
I gained an introduction to the eight CISSP security domains:

1. Security and Risk Management
2. Asset Security
3. Security Architecture and Engineering
4. Communication and Network Security
5. Identity and Access Management
6. Security Assessment and Testing
7. Security Operations
8. Software Development Security

### 5. Cybersecurity Tools
I learned about the purpose of tools and technologies used by security analysts:

| Tool or Technology | Purpose |
|---|---|
| SIEM tools | Collect and analyze security logs to help detect threats. |
| Packet analyzers | Examine network traffic during investigations. |
| Linux | Support system administration and security tasks. |
| SQL | Retrieve and filter information from databases. |
| Python | Automate repetitive security tasks. |

This course introduced these tools; I am continuing to develop practical skills through further study and labs.

### 6. Security History and Ethics
- How historical cyberattacks influenced modern security practices.
- The importance of privacy, ethical behavior, and following organizational policies.
- Why security professionals must act responsibly when handling sensitive information.

## How This Supports My IT Career

As a CompTIA A+ certified professional working toward an IT support role, this course helped me understand the security reasons behind everyday tasks such as:

- Managing user access and permissions.
- Installing updates and security patches.
- Protecting confidential information.
- Recognizing suspicious activity.
- Reporting potential security incidents.

## My Key Takeaway

Cybersecurity is part of everyday IT support. Understanding security fundamentals helps me troubleshoot responsibly and make better decisions when supporting users and systems.
